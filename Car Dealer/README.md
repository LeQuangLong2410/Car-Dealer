# Car Dealer Website

A premium automotive marketplace experience built with modern frontend technologies.

## Description
This is a high-end frontend portfolio project designed to simulate a real-world car dealership platform. It focuses on providing a seamless, high-performance user interface with a premium aesthetic. The project demonstrates advanced DOM manipulation, state management (using localStorage), and professional UI/UX principles including responsive design and interactive animations.

## Features
- **Modern Car Listing UI**: A clean, grid-based layout showcasing available vehicles with hover effects and smooth transitions.
- **Advanced Search & Filter**: Real-time filtering by brand, price range, and keyword search for a fast user experience.
- **Interactive Car Details**: Dynamic view for vehicle specifications without page reloads, providing a smooth navigation flow.
- **Shopping Cart System**: Fully functional cart using `localStorage` to persist data across sessions, allowing users to add, remove, and update quantities.
- **Contact Form Validation**: Robust frontend validation for lead generation forms with real-time feedback and success states.
- **Dark Mode Support**: A professionally curated dark theme that respects user preferences and improves accessibility.
- **Premium Animations**: Integrated with ScrollReveal for a polished, "fade-in" entry of components as the user scrolls.
- **Fully Responsive**: Optimized for all devices, from mobile phones to high-resolution desktops.

## Technologies Used
- **HTML**: Semantic structure for SEO and accessibility.
- **CSS**: Custom properties (CSS variables), Flexbox, Grid, and complex animations for a premium feel.
- **JavaScript**: Modular logic for search filtering, cart management, and UI interactions.
- **Remix Icon**: Sleek, vector-based iconography.
- **ScrollReveal**: For elegant scroll-based entry animations.

## Installation / Run Project
To run this project locally, follow these simple steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/lequanglong/car-dealer-website.git
   ```
2. **Navigate to the project folder**:
   ```bash
   cd car-dealer-website
   ```
3. **Open the project**:
   - Simply open `index.html` in your favorite web browser.
   - Alternatively, use a local server (like Live Server in VS Code) for the best experience.
